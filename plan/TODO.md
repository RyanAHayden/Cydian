- [ ] **F97** Cydian Account (user 2026-11-18: minimal, free to host): keep your settings, sources, ignored upgrades, installed-app records and signing certificate on cydian.dev, so a new phone, a reinstall or the website gets them back. No email, no password: the account is a random 128-bit **account key** made on the device (shown once as a code and a `cydian://account?k=` link / QR to save or open on another device; kept in the keychain in the app, IndexedDB on the site). Everything is encrypted on the device (AES-GCM, key from the account key with HKDF; Web Crypto in both builds), so cydian.dev only ever holds ciphertext and can't read a certificate. The Worker stores one blob per account in the existing KV namespace (`HOSTED`, a new `acct:` prefix; Cloudflare's free tier: 1 GB, 1,000 writes/day), keyed by SHA-256 of a separate HKDF-derived id, so the key never reaches the server: `PUT /api/account/<id>` (body ≤ 256 KB, an `If-Match` version so two devices don't overwrite each other: the second gets 409 and merges), `GET` (404 when none), `DELETE`. Rate-limit per address, refuse bodies over the cap, no logging of bodies.
