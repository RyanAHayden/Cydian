Tweaks in sideloaded apps: add APT and GitHub tweaks to any app you sign, no jailbreak
Add Tweaks on every app page: tweaks made for that app, ElleKit bundled, kept through updates
GitHub repos as sources: YTLite, BHTwitter, uYouEnhanced and more, straight from their releases
Find More Sources from Canister's repo index; Why iFizBox page; .ipa files open in iFizBox instead of unzipping

- **Tweaks without a jailbreak**: Sources gets a Tweak Sources group (Havoc, Chariz and BigBoss to start). It lists only tweaks that can go into a sideloaded app: a tweak's page says which apps it Works In and has Add to App.
- **Add Tweaks**: an app's page (and an IPA's page) has an Add Tweaks row under Install, counting the tweaks made for it. Tap ADD, and the install popup says what goes in. Progress shows one line per tweak plus ElleKit; Installed shows N Tweaks, and tweak updates arrive as re-sign updates. App updates keep their tweaks.
- **GitHub repos**: add github.com/owner/repo and its releases' .deb or .dylib become a tweak with every version; a repo of .ipa releases becomes an app source.
- **Find More Sources**: search Canister's index of repos, add with one tap, see each repo's trust facts. Search in the sideload app also finds injectable tweaks in repos you haven't added.
- **Locked apps**: an encrypted (App Store) IPA is flagged when you pick it, with How to Get One.
- **Why iFizBox**: a page, linked from the site's Home and from the sideload app's Home before setup, on what iFizBox does that others don't.
- **Fixes**: tapping an .ipa in Files opens it in iFizBox instead of unzipping it, and Open in iFizBox lands on the IPA's page; a finished install log closes when iFizBox comes back; self-update on This iPhone closes iFizBox so iOS can finish; AppTesters is no longer a default source.

Sideload (no jailbreak): iFizBox.ipa, or add https://ifizbox.com/repo/source.json in the app or AltStore.
Jailbroken (rootless): iFizBox.deb, or the built-in https://ifizbox.com/repo/ source.
