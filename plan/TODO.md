Everything is encrypted on the device (AES-GCM, key from the account key with HKDF; Web Crypto in both builds), so cydian.dev only ever holds ciphertext and can't read a certificate. The Worker stores one blob per account in the existing KV namespace (`HOSTED`, a new `acct:` prefix; Cloudflare's free tier: 1 GB, 1,000 writes/day), keyed by SHA-256 of a separate HKDF-derived id, so the key never reaches the server: `PUT /api/account/<id>` (body ≤ 256 KB, an `If-Match` version so two devices don't overwrite each other: the second gets 409 and merges), `GET` (404 when none), `DELETE`. Rate-limit per address, refuse bodies over the cap, no logging of bodies. The payload is `websitePayload()`'s shape (screens/importlink.js: sources, settings, holds, identity) plus core/installed.js's records, versioned (`v: 1`). Settings > Account (iOS 6 grouped table): Create Account / Sign In With Key, Sync Now, Last Synced, Show Account Key, Delete Account (red, asks first); a Sync Certificate switch (on by default, with a footer saying it's encrypted with your key). Signing in is a read. Writes are batched (user 2026-11-18, the free tier's 1,000 writes/day): save once when the app goes to the background or the page is hidden, only if something changed since the last save, plus Sync Now; read on launch.
