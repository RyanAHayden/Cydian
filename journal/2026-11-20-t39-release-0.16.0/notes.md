Tweak injection unpacks zstd and bzip2 .debs, and bundles ElleKit for tweaks that need Substrate
All Apps row on Sources and AltStore source pages: every app, newest version
Installation & Signing simplified: one Install Apps With row; faster This iPhone settings
Smoother: pages, sheets and alerts slide when they grow or shrink; fixes for cancelled installs and Paste

- **Tweak injection**: .debs packed with zstd or bzip2 now unpack; a tweak that links CydiaSubstrate gets ElleKit added instead of a refusal.
- **Sources**: an All Apps row lists every AltStore app once (newest version), on the Sources tab and on each AltStore source page.
- **Safety**: IPAs are hashed when signed so Report as Malicious can send the hash; known-malware hashes are refused before signing. The exposure note names the newest iOS update your iPhone model can actually get.
- **Settings**: Installation & Signing has one Install Apps With choice (This iPhone or Paired); This iPhone's status rows load at once and in place.
- **Fixes**: a cancelled or unconfirmed install is never recorded as Installed; Paste in Sign In With Key works; Open in iFizBox logs every step to Console Logs; What's New and Install IPAs slide in properly.

Sideload (no jailbreak): iFizBox.ipa, or add https://ifizbox.com/repo/source.json in the app or AltStore.
Jailbroken (rootless): iFizBox.deb, or the built-in https://ifizbox.com/repo/ source.
